I kept document principles in the document runbook rather than adding a separate principles file that every writing task would immediately need. Host-specific monitoring is separate, so Codex does not need to load Claude Code's background-process details.

The component catalog remains the markup source of truth. The document runbook keeps a compact selector, while repeated component examples and the repeated gotchas checklist came out of the main skill. Choice markup points to the same catalog.

Free writing: three directions

Same post, same states, different layout. Each opens on the reading screen; the step strip at the top of every screen walks the six steps, and the branches hang off steps 1, 2 and 4.

Settled for all three (Q7): whatever the reviewer writes in one sitting is one edit and one rail card. Enter at the end of an existing block continues that edit. The directions differ on:
  • how you start writing where there is no text
  • how you pick paragraph, heading, or list

A. Block menu on the bar

Argues that block type belongs beside B and I, named in words, and that new text starts from a line that shows only under the pointer.

Signature: the thin insertion line labeled "+ Write here".

B. Type like Markdown

Argues for no new controls at all: type # or - and the line converts live, and any empty space takes a click.

Signature: the live conversion of "# " into a heading.

C. Growing frame, gutter plus

Argues that every place to write should be visible at once, with a one-click type row on a bar that rides the frame's bottom edge.

Signature: the frame that grows to hold the whole sitting, bar on its bottom edge.

Every screen in a direction:

  • Steps: reading, edit state, new block, make it a header, type it, paragraphs and a list, waiting, placed, proofread question, after Yes, after Keep mine
  • Branches: editing an existing paragraph and pressing Enter, a blank notes document from the terminal, a reload mid-writing, the empty rail

Controls with a dotted underline are not wired.

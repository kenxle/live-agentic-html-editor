Garden plan

Alder Street community plot · spring

Eight families share the plot this year. This page is the plan everyone agreed to at the March meeting.

Beds

We will utilize the four raised beds along the fence for tomatoes and beans, and keep the herb spiral by the gate.

Watering

Two volunteers water every week, on a rota posted inside the shed door. Anyone away for a week swaps a day with a neighbour.

Budget

Seeds, soil and a new hose will cost about as much as last year. The treasurer holds the receipts.

Tools

The shed code stays the same. Return the wheelbarrow upside down so it does not fill with rain.
